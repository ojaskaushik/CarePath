
# CarePath 🩺

**Your health, your next step.**

CarePath is a full-stack health information and pharmacy discovery platform designed to help users explore health concerns, learn about evidence-based self-care, understand over-the-counter medications, and locate nearby pharmacies.

## Features

- 🔎 Search health concerns and symptoms
- 🏠 Explore evidence-based self-care information
- 💊 Learn about over-the-counter medications
- 📍 Find nearby pharmacies
- 👤 Ask questions without creating an account
- 🔐 Create an account to save conversations
- 📱 Responsive interface for desktop and mobile

## Tech Stack

- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Backend:** Python, FastAPI
- **Database:** PostgreSQL
- **Integrations:** Health Canada Drug Product Database, Google Maps

## Development Status

🚧 CarePath is currently under active development.

## Disclaimer

CarePath provides educational health information and is not a substitute for professional medical advice, diagnosis, or treatment.
